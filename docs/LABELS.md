# Repository GitHub Labels

Use labels to make it easy for contributors to find small, useful PRs and categorize incoming issues.

## Issue Types and Domains
- `bug`: Something isn't working or website breakage caused by blocking.
- `enhancement`: New feature request or tracker domain additions to the catalog.
- `documentation`: Improvements or additions to documentation, README, or contributor guides.
- `testing`: Tests, test fixtures, scripts, or coverage improvements.
- `ux`: User experience, popup layout, copy, styling, or interface clarity.
- `browser-extension`: Chrome extension, Manifest V3, DNR, or service worker behavior.
- `privacy`: Privacy behavior or local-only design.
- `security`: Security hardening or trust boundaries.
- `ci`: Continuous integration and automation workflows.

## Contributor Signals
- `good first issue`: Small, well-scoped tasks curated by maintainers for newcomers.
- `help wanted`: Maintainers welcome outside contributions on this task.

## Triage and Scope
- `priority: high` / `priority: medium`: Maintainer triage priority.
- `size: small` / `size: medium` / `size: large`: Expected scope of the contribution.
- `duplicate`, `invalid`, `question`, `wontfix`: Standard issue triage resolutions.
